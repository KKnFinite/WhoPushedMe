# WHO PUSHED ME?! Brand System

This file defines the approved application palette and the planned typography roles.

## Official palette

### Core neutrals
- WPM Night — `#050907`
- WPM Charcoal — `#111611`
- WPM Smoke — `#2A2F28`
- WPM Cream — `#E9E1C8`

### Greens
- WPM Deep Green — `#173326`
- WPM Fairway Green — `#214534`
- WPM Moss Green — `#355B45`
- WPM Accent Green — `#4E7A5D`

### Oranges
- WPM Burnt Orange — `#D96D3B`
- WPM Ember Orange — `#E9783E`
- WPM Danger Orange — `#F25C1D`

### Gold
- WPM Scorecard Gold — `#D4A62A`

Gold is an accent color. It is intended for focus rings, trim, badges, scorecard details, small highlights, and other emphasis rather than large primary surfaces.

## Usage hierarchy
- Greens: primary branded surfaces, panels, secondary controls.
- Oranges: primary calls to action, selected states, warnings, high-energy interactions.
- Gold: accents and focus/highlight details.
- Cream: readable light text and light input surfaces.
- Night / charcoal / smoke: page foundations, dark cards, overlays, and depth.

## Typography plan
The planned custom family is **WPM Sans** with three weights:
- WPM Sans Light — 300
- WPM Sans Regular — 400
- WPM Sans Bold — 700

CSS tokens already exist as `--font-wpm-light`, `--font-wpm-regular`, and `--font-wpm-bold`. The custom font files are not yet present, so the application continues to use fallbacks until the WPM font is created and approved.
